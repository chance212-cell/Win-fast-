# WIN FAST — Full-stack demo

A responsive sports/games-style website prototype with a small Node/Express + SQLite backend.

## Run locally
1. Install Node.js 18+.
2. In this folder run: `npm install`
3. Run: `npm start`
4. Open `http://localhost:3000`

## Included
- Responsive Win Fast UI
- Demo sports/events and games
- Demo bet slip interactions
- Register/login with hashed passwords
- JWT session
- SQLite user database
- Saved selections API
- Wallet/profile UI (demo only)

## Not included
This is intentionally **not a real-money gambling system**. No payment processing, deposits, withdrawals, settlement, or live wagering is enabled. For a production service, licensing, age/identity controls, responsible-gaming controls, jurisdiction rules, security review, and compliant payment/wagering infrastructure would need to be implemented by qualified professionals.
